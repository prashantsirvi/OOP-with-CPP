# Program 11

## Aim
To create and use an abstract class.

## Problem Statement
Write a C++ program with an abstract Shape class containing a pure virtual area() function and implement that function in a Rectangle class.

## Concepts Used
- Abstract class
- Pure virtual function
- Virtual function
- Function overriding
- Derived class

## Sample Input
No user input. A Rectangle object is created with length 8 and width 4.

## Sample Output
Rectangle Area: 32

## Explanation
A class containing at least one pure virtual function is abstract and cannot be instantiated directly. Shape declares area() as pure virtual, so Rectangle must provide its own implementation.
