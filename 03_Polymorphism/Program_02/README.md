# Program 02

## Aim
To calculate the areas of different shapes using overloaded functions.

## Problem Statement
Write a C++ program that uses function overloading to calculate the area of a square, rectangle, and circle.

## Concepts Used
- Function overloading
- Compile-time polymorphism
- Function parameters
- Square area
- Rectangle area
- Circle area

## Sample Input
Square side = 5, rectangle length = 6 and width = 4, circle radius = 2.0.

## Sample Output
Square Area: 25
Rectangle Area: 24
Circle Area: 12.5664

## Explanation
The overloaded calculateArea() functions are selected according to their parameter lists. One integer parameter calculates a square, two integer parameters calculate a rectangle, and one double parameter calculates a circle.
