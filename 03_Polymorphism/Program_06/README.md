# Program 06

## Aim
To overload the > operator for comparing two user-defined objects.

## Problem Statement
Write a C++ program to compare two Distance objects using an overloaded greater-than operator.

## Concepts Used
- Operator overloading
- Relational operator
- User-defined objects
- Comparison
- Boolean result

## Sample Input
No user input. The distances are 120 meters and 90 meters.

## Sample Output
First distance: 120 meters
Second distance: 90 meters
First distance is greater

## Explanation
The operator>() function compares the meters stored in two Distance objects and returns the result of the comparison. This allows the expression first > second to be used directly with user-defined objects.
