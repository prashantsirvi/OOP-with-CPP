# Program 01

## Aim
To implement compile-time polymorphism using function overloading.

## Problem Statement
Write a C++ program to demonstrate function overloading by defining multiple add() functions with different parameter lists.

## Concepts Used
- Function overloading
- Compile-time polymorphism
- Function parameters
- Function calls
- Return values

## Sample Input
10, 20; 2.5, 3.7; and 10, 20, 30 are used as predefined arguments.

## Sample Output
Sum of two integers: 30
Sum of two doubles: 6.2
Sum of three integers: 60

## Explanation
Function overloading allows multiple functions to have the same name with different parameter lists. The compiler selects the appropriate add() function based on the number and types of arguments. The return type alone cannot distinguish overloaded functions.
