# Program 06

## Aim
To understand the automatic execution of a constructor when an object is created and a destructor when the object is destroyed.

## Problem Statement
Write a C++ program that demonstrates the execution of a constructor and destructor for an object and displays messages showing their execution order.

## Concepts Used
- Constructor
- Destructor
- Object creation
- Object lifetime
- Automatic initialization and cleanup

## Sample Input
No user input. A Demo object is created inside main.

## Sample Output
Constructor called
Destructor called

## Explanation
When object d is created, the constructor executes automatically. When the object reaches the end of its lifetime, the destructor executes automatically. The output demonstrates construction followed by destruction.
