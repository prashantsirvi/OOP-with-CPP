# Program 03

## Aim
To understand how arrays store multiple values and how a for loop can access and display array elements.

## Problem Statement
Write a C++ program to store the marks of five students in an array and print all the stored marks using a loop.

## Concepts Used
- Array
- Array indexing
- for loop
- Index variable
- Sequential access

## Sample Input
No user input. The array is initialized with 78, 82, 91, 67, and 88.

## Sample Output
78 82 91 67 88

## Explanation
The program creates an integer array containing five marks. A for loop runs from index 0 to index 4, and marks[i] accesses each element for display.
