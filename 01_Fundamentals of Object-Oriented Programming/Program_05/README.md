# Program 05

## Aim
To understand the basic object-oriented concepts of a class and an object in C++.

## Problem Statement
Write a C++ program to create a Student class containing student details and a member function to display those details using an object.

## Concepts Used
- Class
- Object
- Data members
- Member function
- Dot operator

## Sample Input
No user input. The object is assigned name = Amit and age = 20.

## Sample Output
Amit 20

## Explanation
Student acts as a blueprint containing data members name and age and the member function show(). Object s1 is created, its values are assigned using the dot operator, and show() displays them.
