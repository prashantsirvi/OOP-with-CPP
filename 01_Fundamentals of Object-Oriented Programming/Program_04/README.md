# Program 04

## Aim
To understand the use of functions in C++ for performing reusable operations and returning a result.

## Problem Statement
Write a C++ program containing an addition function that accepts two integers and returns their sum.

## Concepts Used
- Function
- Function prototype
- Function call
- Parameters
- Return value

## Sample Input
No user input. The program uses a = 10 and b = 20.

## Sample Output
Sum = 30

## Explanation
The add function is declared with a prototype before main. main calls add(a, b); the parameters receive the values, the function calculates their sum, and the result is returned.
