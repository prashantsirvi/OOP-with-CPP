# Unit 01 — Fundamentals of Object-Oriented Programming

## Overview

This unit focuses on the fundamentals of C++ programming that form the foundation for understanding Object-Oriented Programming. It covers basic data types, decision-making using if-else, loops and arrays, functions, classes and objects, constructors and destructors, static members, inline functions, and friend functions.

The programs in this unit are designed to introduce fundamental C++ programming concepts and gradually build an understanding of basic Object-Oriented Programming concepts through practical examples.

## List of Programs

### 1. Basic Data Types

Demonstrates the use of basic C++ data types such as `int`, `char`, and `float` to store different types of student information, including roll number, grade, and fee amount.

### 2. if-else

Demonstrates decision-making using the `if-else` statement. The program checks a student's marks and determines whether the student has passed or failed based on the given condition.

### 3. Loop and Array

Demonstrates the use of an array to store the marks of five students and a `for` loop to access and display each element of the array sequentially.

### 4. Functions

Demonstrates the use of a function to perform addition of two numbers. It introduces function declaration, parameters, function calls, and return values for creating reusable code.

### 5. Class and Object

Demonstrates the basic Object-Oriented Programming concepts of a class and an object. The program defines a `Student` class containing student details and a member function for displaying those details.

### 6. Constructor and Destructor

Demonstrates the automatic execution of a constructor when an object is created and a destructor when the object reaches the end of its lifetime. The program displays the order in which these functions are executed.

### 7. Static Member

Demonstrates the use of a static data member shared by all objects of a class. The program uses a static member to count the number of `Student` objects created.

### 8. Inline and Friend Function

Demonstrates the use of an inline member function and a friend function. The inline function provides access to a private data member through a getter, while the friend function is granted permission to directly access the private data.

## Learning Objective

After completing the programs in this unit, the learner should be able to understand and implement fundamental C++ programming concepts, use basic data types and control structures, work with arrays and functions, create classes and objects, understand constructors and destructors, use static members, and apply inline and friend functions as introductory Object-Oriented Programming concepts.
