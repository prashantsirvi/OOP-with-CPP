# Program 01

## Aim
To understand and use basic C++ data types such as int, char, and float to store different kinds of student information.

## Problem Statement
Write a C++ program to store a student's roll number, grade, and fee amount using appropriate basic data types, and display the stored values.

## Concepts Used
- Basic data types
- int data type
- char data type
- float data type
- Output using cout

## Sample Input
No user input. Predefined values: roll number = 101, grade = A, and fee = 12500.50.

## Sample Output
Roll No: 101
Grade: A
Fee: 12500.5

## Explanation
The program demonstrates how different basic data types represent different kinds of information. int stores the whole-number roll number, char stores the single-character grade, and float stores the decimal fee amount. cout displays the values.
