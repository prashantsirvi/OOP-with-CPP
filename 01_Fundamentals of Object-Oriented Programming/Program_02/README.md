# Program 02

## Aim
To understand decision-making in C++ using the if-else selection statement.

## Problem Statement
Write a C++ program to check whether a student's marks indicate a pass or fail. A student is considered passed when the marks are 40 or above; otherwise, the student is considered failed.

## Concepts Used
- Selection statement
- if statement
- else statement
- Relational operator
- Conditional execution

## Sample Input
No user input. The program uses the predefined marks value 45.

## Sample Output
Pass

## Explanation
The program stores the student's marks and checks whether they are greater than or equal to 40. If true, it displays Pass; otherwise, the else block displays Fail.
