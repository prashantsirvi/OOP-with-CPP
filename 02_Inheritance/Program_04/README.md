# Program 04 — Multilevel Inheritance

## Aim
Implements the Person -> Employee -> Manager three-level inheritance chain.

## Concept
This program demonstrates **Multilevel Inheritance** as part of Unit II: Inheritance.

## Source File
`4. Multilevel inheritance.cpp`

## C++ Standard
C++17 or later.

## Compile
```bash
g++ -std=c++17 4. Multilevel inheritance.cpp -o program04
```

## Run
```bash
./program04
```

### Windows / MinGW
```bash
g++ -std=c++17 4. Multilevel inheritance.cpp -o program04.exe
program04.exe
```

## What to Understand
- Identify the classes involved.
- Identify which class is the base and which is derived, where applicable.
- Understand why the selected inheritance/OOP mechanism is used.
- Trace the important function calls and constructor calls before modifying the program.

## Customization
The example data, names and internal structure are intentionally written for this repository. You can change the input values and extend the classes after understanding the program.
